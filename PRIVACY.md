# Datenschutzerklärung – Lumi Upload / Privacy Policy

*Stand / Last updated: 27.11.2026*

## Deutsch

**Lumi Upload** ist ein privates Werkzeug des Betreibers der YouTube-Kanäle „Faktenfunke“ und
„CurioSpark“. Es lädt ausschließlich eigene Videos auf diese eigenen Kanäle hoch.

- **Genutzte Dienste:** Lumi Upload verwendet die YouTube API Services (YouTube Data API v3).
  Es gelten die [YouTube-Nutzungsbedingungen](https://www.youtube.com/t/terms) und die
  [Datenschutzerklärung von Google](https://policies.google.com/privacy).
- **Welche Daten:** Lumi Upload greift nur auf die Kanäle des Betreibers zu (Videos hochladen,
  Titel/Beschreibung/Thumbnail/Playlist setzen). Es werden **keine Daten anderer Personen** erhoben,
  gespeichert oder weitergegeben. Es gibt keine Nutzerkonten, kein Tracking und keine Werbung.
- **Speicherung:** Der Zugriffsschlüssel (OAuth-Refresh-Token) wird verschlüsselt als
  GitHub-Actions-Secret gespeichert und nur für die Uploads verwendet.
- **Widerruf:** Der Zugriff kann jederzeit unter https://myaccount.google.com/permissions widerrufen werden.
- **Kontakt:** über die Kanalinfo der oben genannten YouTube-Kanäle.

## English

**Lumi Upload** is a private tool of the owner of the YouTube channels "Faktenfunke" and
"CurioSpark". It only uploads the owner's own videos to these own channels.

- **Services used:** Lumi Upload uses the YouTube API Services (YouTube Data API v3).
  The [YouTube Terms of Service](https://www.youtube.com/t/terms) and the
  [Google Privacy Policy](https://policies.google.com/privacy) apply.
- **Data:** Lumi Upload only accesses the owner's channels (upload videos, set title, description,
  thumbnail and playlist). It does **not collect, store or share data of any other person**.
  There are no user accounts, no tracking and no ads.
- **Storage:** The access token (OAuth refresh token) is stored encrypted as a GitHub Actions secret
  and used only for the uploads.
- **Revoking access:** https://myaccount.google.com/permissions
- **Contact:** via the "About" section of the YouTube channels named above.
